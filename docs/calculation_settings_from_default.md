# 修正内容ごとの設定方法（自立を基本とする）

対象：2026-10-23時点のmain（製品版ver.1.6.0、入力仕様 `261023`）。画面上の名称に合わせ、本書では従来方式を「自立」と記す。
基本は自立のまま使用し、TG固有の風量・送風機電力の計算が必要な場合にTGへ切り替える。

各項目は、初期状態からその修正だけを適用する手順である。3.1から順に変更を積み重ねる手順ではない。
節番号3.1～3.7は比較資料の項目番号であり、画面の①～⑧とは別である。
住宅条件・地域・外皮・VAV・機器仕様は、比較するケースに合わせて別途設定する。
3.1～3.7の個別比較は、暖房・冷房ともダクト式セントラル空調機（方式1）を対象とする。
ルームエアコン活用型（方式2）の熱源置換は、後半の「ルームエアコン活用型の設定」で説明する。

## 計算方式の選び方

| 節 | 修正内容 | 計算方式 | 自立を基本とした操作 |
| --- | --- | --- | --- |
| 3.1 | VAVなしの熱源機の出口温度 | **どちらでもよい（自立を推奨）** | 出口温度の補正をON |
| 3.2 | VAVの機構の定義の明確化 | **どちらでもよい** | 専用の式切替はない。必要に応じてVAVを設定 |
| 3.3 | 最低風量・送風機電力の計上方法 | **修正案の再現にはTG** | TGの風量・電力計上の比較条件を選択 |
| 3.4 | 送風機の風量と消費電力の累乗式 | **修正案の再現にはTG** | TGの送風機特性の比較条件と指数nを選択 |
| 3.5 | 全般換気機能なしの扱い | **修正案全体の再現にはTG** | TGの全般換気なしの比較条件を選択 |
| 3.6 | 冷房の間仕切り熱移動の符号 | **どちらでもよい（自立を推奨）** | 間仕切壁熱移動の符号補正をON |

「どちらでもよい」は、該当する修正をいずれの方式でも設定できるという意味である。
TGを選択するだけで自立と同じ計算になるわけではない。TGで単独の修正を比較するときは、下記の個別比較条件を選ぶ。
他の入力・補正が異なる場合の数値一致を意味しない。

## 3.1 VAVなしの熱源機の出口温度

**内容：** 最も厳しい居室の要求値で出口温度を決める。暖房時は区画別要求温度の最大値、冷房時は最小値を採用する。出口温度の上下限制約は、その後に適用する。

**計算方式：どちらでもよい。通常は自立のままとする。**

**デフォルトから変更する部分：**

- 「⑧ 詳細設定・比較検証」の「計算方法の比較切替」を開く。
- 「熱源機出口温度を区画別要求温度から決定する」を **OFF → ON** にする。

VAVなしの比較では暖房・冷房のVAVを「採用しない」、最低風量を「入力しない」とする。
TGで同じ修正だけを確認する場合は、⑧の「TGの計算モード」で「出口温度だけを修正」を選ぶ。
個別比較を選ぶと、この補正は自動的にONになる。

## 3.2 VAVの機構の定義の明確化

**内容：** VAVを「居室別風量調整機能」として、名称と定義を明確にする。

**計算方式：どちらでもよい。通常は自立のままとする。**

**デフォルトから変更する部分：** この定義変更に対応する専用の計算切替はない。
VAVありのケースでは、暖房設備・冷房設備の「VAV」を、ともに **採用しない → 採用する** にする。

定義の明確化と、VAVの有無による計算条件の変更は区別する。ほかの修正と組み合わせる場合、計算方式はその修正の手順に従う。

## 3.3 熱源機の最低風量と送風機電力の計上方法

**内容：** 最低風量を暖房期・冷房期別に入力し、入力しない場合は設計風量とする。送風機の総消費電力を求めてから、最低風量までの電力を換気分として分け、残りを暖冷房分に計上する。

**計算方式：修正案の再現にはTGを使用する。**

**デフォルトから変更する部分：**

- 「計算方式」を **自立 → TG** にする。
- ⑧の「TGの計算モード」で **最低風量・送風機の計上方法を修正（n＝1）** を選ぶ。
- 最低風量を指定する場合は、暖房・冷房それぞれの「風量・送風機電力」で「最低風量の入力」を **入力しない → 入力する** にし、「最低風量」に比較する値を入力する。

暖房・冷房で同じ最低風量を比較する場合は、両方に同じ値を入力する。
「最低風量を入力しない」ケースでは、最低風量の入力を「入力しない」のままとする。
設計風量も既定算定を用いる場合は「入力しない」のままにし、欄に残る数値を直接入力として有効にしない。

自立にも最低風量の入力欄はあるが、風量配分と送風機電力の処理が異なるため、同じ値の入力だけでこの修正案の再現とはならない。

**最低風量の式だけを変更する比較：** 電力計上方法を保持し、式(39)だけを変更する場合は、TGの **最低風量の式だけを変更** を選ぶ。この条件では最低風量を「入力しない」にすると元の式(39)を使い、設計風量へは変更しない。

**中間期の入力範囲：** ver.1.6.0では中間期の最低風量を独立して指定する機能は未対応である。TGの風量・送風機比較では、暖房・冷房の最低風量の大きい方を中間期に用いる。入力なしの場合も、暖房・冷房の設計風量の大きい方を用いる。

## 3.4 送風機の風量と消費電力の関係

**内容：** 原点と設計風量時の点を通る累乗式で送風機の消費電力を求める。3.3の風量・電力計上方法の修正を前提とする。

**計算方式：修正案の再現にはTGを使用する。**

**デフォルトから変更する部分：**

- 「計算方式」を **自立 → TG** にする。
- ⑧の「TGの計算モード」で **送風機特性を比較（指数nを選択）** を選ぶ。
- ⑤「TG｜暖冷房共通設定」で指数nを **1・1.5・2・3** から選ぶ。
- 暖房・冷房の最低風量を比較条件に合わせて入力する。入力なしのケースでは「入力しない」のままとする。

この比較条件に3.3の修正を含むため、3.3の比較条件を別途選ぶ必要はない。

## 3.5 全般換気機能なしの場合の扱い

**内容：** 全般換気量を送風量の下限とせず、中間期も最低風量で送風する。最低風量までの送風機電力を換気分に計上する。

**計算方式：修正案全体の再現にはTGを使用する。**

**デフォルトから変更する部分：**

- 「計算方式」を **自立 → TG** にする。
- ⑧の「TGの計算モード」で **全般換気なし：換気量下限なし・停止なし** を選ぶ。
- 暖房・冷房の最低風量を比較条件に合わせて入力する。入力なしのケースでは「入力しない」のままとする。

この比較条件により、暖房・冷房とも全般換気機能なし、指数n＝1が適用される。
参考条件や中間期停止を確認するときは、比較条件を次のように変更する。

| 確認する条件 | ⑧のTGの計算モード |
| --- | --- |
| 全般換気量を下限とする・停止しない（参考） | 全般換気なし：換気量下限あり・停止なし（参考） |
| 全般換気量を下限としない・停止しない | 全般換気なし：換気量下限なし・停止なし |
| 全般換気量を下限としない・中間期に停止する | 全般換気なし：換気量下限なし・中間期停止 |

自立にも「全般換気なし時の給気風量下限を補正する」があるが、その補正だけでは、TGの最低風量・中間期運転・電力計上を含む修正案全体にはならない。

## 3.6 間仕切りを通した非居室への熱移動の符号

**内容：** 冷房期の負荷バランス時の冷房顕熱負荷について、非居室からの熱取得を負荷に加えるよう、式(9-2)の符号を修正する。

**計算方式：どちらでもよい。通常は自立のままとする。**

**デフォルトから変更する部分：**

- 「④ 床下・空気搬送」の「建研式との比較・補正」を開く。
- 「冷房時の間仕切壁熱移動を物理的な符号へ補正する」を **OFF → ON** にする。

TGで同じ修正だけを確認する場合は、⑧の「TGの計算モード」で **冷房の間仕切り熱移動の符号だけを修正** を選ぶ。この補正は自動的にONになる。

## 3.7 入力値の定義

**内容：** 入力項目の定義と、機外静圧を含む試験条件を定めた定義書を作成し、評価方法に明記する。

**計算方式：どちらでもよい。通常は自立のままとする。**

**デフォルトから変更する部分：** この項目に対応する専用の画面設定・計算切替はない。

これは入力値の意味や試験条件の整備に関する項目であり、本書の設定操作で定義書の整備を完了するものではない。
既定の機器条件で比較する場合は、機器仕様・設計風量を「入力しない」とする。メーカーの値を直接使う場合は、その値の定義と試験条件を別途確認する。

## ルームエアコン活用型の設定

**内容：** ダクト式の最低風量・送風機電力の修正を用い、熱源の最大出力と消費電力量をルームエアコンの計算に置き換える。送風機の風量・電力はダクト式の既定算定を使用する。

**計算方式：この熱源置換の比較にはTGを使用する。** 自立にも方式2はあるが、TGとは能力・効率・送風機電力などの処理が異なるため、同じ能力を入力するだけでこの比較条件にはならない。

### デフォルトから変更する部分

1. 「計算方式」を **自立 → TG** にする。
2. ⑧の「TGの計算モード」が **標準計算（従来のTG総合・ダクト／RAC）** であることを確認する（初期値のままでよい）。
3. 「⑤ 暖房設備」の「暖房方式」と「⑥ 冷房設備」の「冷房方式」を、ともに **RAC活用型（方式2）** にする。
4. 暖房・冷房それぞれの「風量・送風機電力」で、「最低風量の入力」を **入力しない → 入力する** にして、最低風量を **300 m³/h** にする。
5. ⑥の「TG RAC：定格冷房能力 [W]」、⑤の「TG RAC：定格暖房能力 [W]」と「TG RAC：効率区分（暖冷房共通）」を、次の組合せに合わせる。5.6 kW・いはTGの初期値と同じである。

| 比較する機種 | 定格冷房能力 [W] | 定格暖房能力 [W] | 効率区分 |
| --- | ---: | ---: | --- |
| 4.0 kW・い | 4000 | 5000 | い |
| 5.6 kW・い | 5600 | 6700 | い |
| 5.6 kW・ろ | 5600 | 6700 | ろ |
| 5.6 kW・は | 5600 | 6700 | は |
| 7.1 kW・い | 7100 | 8500 | い |
| 8.0 kW・い | 8000 | 9500 | い |

機種欄のkWは定格冷房能力を表す。画面にはW単位で入力し、暖房能力も別に設定する。
ここに示す暖房能力は比較用に指定した組合せであり、すべての実機に共通する値ではない。
TG用の能力・効率区分を使用し、自立用の最大能力や定格効率の入力で代用しない。

### 初期値を維持・確認する項目

| 項目 | 設定 |
| --- | --- |
| ⑤ TG：送風機の指数 n（暖冷房共通） | **1** |
| 全般換気機能 | 暖房・冷房とも **あり** |
| 設計風量の入力 | 暖房・冷房とも **入力しない** |
| 小能力時高効率型コンプレッサー | 暖房・冷房とも **評価しない** |
| 熱源機出口温度を区画別要求温度から決定する | **OFF** |
| 冷房時の間仕切壁熱移動を物理的な符号へ補正する | **OFF** |
| 熱交換型換気設備 | **設置しない** |
| 外部の気象・暖冷房負荷ファイル | 使用しない。組込みデータを使用 |

床下空調・熱の繰越・熱源機の全体風量固定は、TGへの切替時にOFFになる。
自立専用の換気風量下限補正・VAV前の配分変更・区画別風量上限方式は、TGでは使用せず非表示になる。
これらの非表示項目をTG用に入力し直す必要はない。

TG標準計算では、出口温度・間仕切り熱移動の補正は自動でOFFにならない。
以前の比較でONにした場合は、今回の比較前に明示的にOFFに戻す。
「送風機特性を比較」などの個別比較は方式1用であるため、RACではTG標準計算を選ぶ。

暖房・冷房とも、ダクトは **全てもしくは一部が断熱区画外である** とする。

### 比較対象のダクト式と結果の読み方

比較対象のダクト式は、上記の住宅・外皮・VAV・最低風量300 m³/h・n＝1・全般換気ありを維持し、暖房・冷房を **ダクト式セントラル空調機（方式1）** にする。
機器仕様・設計風量は **入力しない** とする。TG標準計算のまま比較でき、TG RACの能力・効率区分は方式1の計算には使わない。

| 比較する項目 | 出力・算定方法 |
| --- | --- |
| 暖冷房と換気の一次エネルギー合計 | 画面の **TG比較合計**。年間CSVの `E_total_TG [MJ/year]` |
| 熱源機 | 暖冷房合計から暖房・冷房の未処理負荷の一次エネルギー相当値を差し引く。暖冷房分の送風機電力を含む |
| 未処理負荷 | 暖房・冷房の「うち未処理」の合計 |
| 送風機の換気分 | 年間CSVの `E_fan_vent [MJ/year]` |
| 第五章の換気 | 年間CSVの `E_vent_ch5 [MJ/year]` |
| ダクト式に対する比率 | 同じ地域・外皮・VAVのダクト式のTG比較合計を分母とする |

各値は丸め前に集計する。整数に丸めた内訳の和が合計と1 MJ程度異なる場合がある。
比率も通常は丸め前の合計で求めるが、資料との照合では分子・分母を整数に丸めてから算定しているかも確認する。丸め順序により小数1桁の比率が0.1ポイント異なる場合がある。

## 比較時の出力と設定の確認

- 出口温度・最低風量の式だけ・間仕切り符号の単独比較では、暖房・冷房・暖冷房合計を確認する。
- 風量と送風機電力の計上を含むTG比較では、暖冷房合計に「送風機の換気分」「第五章の換気」を加えた「TG比較合計」を確認する。
- 「うち未処理」は暖房・冷房に含まれるため、合計に再加算しない。
- 自立で元の式と比較する場合は、対象の補正をOFFにし、それ以外の条件をそろえる。TGでは「現行式（比較基準）」を使う。換気を含むTG比較合計が必要な場合は、現行側もTGの比較基準で集計する。
- TGの個別比較は対象外の補正を正規化する。自立では自動的にそろわないため、他の補正・風量配分・機器条件が初期値か確認する。
- TGから自立へ戻す操作は、入力全体を初期状態へ戻す操作ではない。個別比較では初期入力から開始するか、保存した基準入力を読み込む。

TGの詳しい算定・集計範囲は[自立方式とTG方式の切替](tg_calculation_method.md)を参照。
