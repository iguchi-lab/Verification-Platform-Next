# 床下を給気経路に用いる全館空調計算：7つの変更点

## 1. この文書の目的

本計算法は、ダクト式全館空調の給気を1階床下へ通し、床下空気から床面を
介して居室・非居室へ熱を供給する方式を扱う。

従来の計算法には「床下を外部側の熱損失経路として扱った住宅負荷」と
「床下を給気経路として利用する今回の熱収支」が混在していた。この二つを
整合させるため、次の7点を変更・確認した。

| 番号 | 変更点 | 要点 |
| ---: | --- | --- |
| 1 | 式 (40)：風量計算用熱源出力 | 1階分を固定面積比ではなく、12室の時刻別負荷比で按分 |
| 2 | 式 (52)：非居室温度 | 非居室全体面積38.93 m²と、床下に接する1階非居室19.04 m²を分離 |
| 3 | 式 (8)/(9)：補正後負荷 | 元負荷の断熱床損失を取り除き、冷房側の符号を物理収支に合わせて修正 |
| 4 | 式 (21)：Pass 1 | 目標床下温度から必要熱源出口温度を直接逆算 |
| 5 | 式 (41)：Pass 2 | 能力制約後の実出口温度から、実床下温度を順方向に計算 |
| 6 | 式 (46)：実居室温度 | 給気と床貫流の2経路を居室熱収支へ反映 |
| 7 | 式 (48)：実非居室温度 | 1階非居室への床貫流と実居室温度を反映 |

結論として、床下は一つの完全混合空間として扱い、同一時刻を
**Pass 1による直接逆算 → 熱源制約 → Pass 2による順計算**の順に1回だけ
解く。反復計算、二分探索、床下温度の $t-1$ 代用は行わない。前時刻状態を
引き継ぐのは、第三章第一節・付録Eの地盤応答モデル内部だけである。

## 3. 計算の前提

### 3.1 空調対象区画と、負荷按分に使う区画は異なる

ダクト式全館空調が直接空調する区画は、1階の区画1・2と、2階の区画3～5で
ある。一方、今回利用する住宅負荷は、別の温熱シミュレーションで全室を
設定温度に保った場合の計算値を組み合わせたものである。このため階別負荷の
按分には、非居室を含む12室すべてを使う。

| $i$ | 室 | 階 | 全館空調の直接対象 | 階別負荷按分 |
| ---: | --- | --- | --- | --- |
| 1 | 居間食堂・台所 | 1階 | 対象 | 1階 |
| 2 | 和室 | 1階 | 対象 | 1階 |
| 3 | 主寝室 | 2階 | 対象 | 2階 |
| 4 | 子供室1 | 2階 | 対象 | 2階 |
| 5 | 子供室2 | 2階 | 対象 | 2階 |
| 6 | 浴室 | 1階 | 対象外 | 1階 |
| 7 | 1階便所 | 1階 | 対象外 | 1階 |
| 8 | 洗面所 | 1階 | 対象外 | 1階 |
| 9 | ホール | 1階 | 対象外 | 1階 |
| 10 | クローゼット | 2階 | 対象外 | 2階 |
| 11 | 2階ホール | 2階 | 対象外 | 2階 |
| 12 | 2階便所 | 2階 | 対象外 | 2階 |

したがって、階別集合は次のとおりである。

```math
\mathcal{I}_{1F}=\{1,2,6,7,8,9\}
```

```math
\mathcal{I}_{2F}=\{3,4,5,10,11,12\}
```

### 3.2 面積は目的ごとに使い分ける

付録Eの表E.6に基づく採用面積は次のとおりである。

| 記号 | 意味 | 採用値 |
| --- | --- | ---: |
| $A_{\mathrm{HCZ},1F}$ | 床下から熱を受ける1階居室 | 46.37 m² |
| $A_{\mathrm{NR}}$ | 非居室全体 | 38.93 m² |
| $A_{\mathrm{NR},1F}$ | 床下に接する1階非居室 | 19.04 m² |
| $A_{\mathrm{uf},A}$ | 床下に接する床面積合計 | 65.41 m² |

1階非居室の内訳は、浴室3.31 m²、1階便所1.66 m²、洗面所3.31 m²、
ホールの床下接触部10.76 m²である。

```math
A_{\mathrm{NR},1F}
=3.31+1.66+3.31+10.76
=19.04\ \mathrm{m^2}
```

ホール全体は13.25 m²だが、玄関に相当する2.49 m²には床下がないため、
床下貫流面積へ含めない。

```math
A_{\mathrm{uf},A}
=A_{\mathrm{HCZ},1F}+A_{\mathrm{NR},1F}
=46.37+19.04
=65.41\ \mathrm{m^2}
```

### 3.3 2種類の床熱貫流率を区別する

元の住宅負荷は、断熱床を通じて外部側へ熱が逃げる条件で計算されている。
この既計上分を取り除くときは、その負荷計算で使った値を用いる。

```math
U_{s,\mathrm{vert}}
=0.5422264459110593\ \mathrm{W/(m^2\,K)}
```

一方、今回の方式では床下から室へ熱を供給するため、床面を断熱しない。
実際の床下・室間の熱移動には、付録Eの最低断熱性能に対応する値を用いる。

```math
U_s=2.223\ \mathrm{W/(m^2\,K)}
```

同じ単位でも役割が異なるため、両値を入れ替えてはならない。

## 4. 変更点1：式 (40)―風量計算用の熱源機出力

### 従来の扱い

Excel床下13では、熱源出力の1階分を固定床面積比で按分していた。

```math
\widehat{Q}_{1F}
=\widehat{Q}
\frac{A_{\mathrm{HCZ},1F}}
{A_{\mathrm{HCZ},1F}+A_{\mathrm{HCZ},2F}}
```

この比率は時刻にかかわらず約0.5714で一定である。しかし実際の1階・2階の
負荷構成は時刻により変わるため、風量計算へ用いる1階出力も負荷に応じて
変える必要がある。

### 採用した扱い

暖房時は12室の暖房負荷 $L_{H,d,t,i}$、冷房時は12室の顕熱負荷
$L_{CS,d,t,i}$を階別に集計する。以下では両者を $L_{\mathrm{mode}}$
と表す。

```math
L_{\mathrm{mode},1F,d,t}
=\sum_{i\in\mathcal{I}_{1F}}L_{\mathrm{mode},d,t,i}
```

```math
L_{\mathrm{mode},2F,d,t}
=\sum_{i\in\mathcal{I}_{2F}}L_{\mathrm{mode},d,t,i}
```

```math
r_{L,1F,d,t}
=
\begin{cases}
\dfrac{L_{\mathrm{mode},1F,d,t}}
{L_{\mathrm{mode},1F,d,t}+L_{\mathrm{mode},2F,d,t}},
& L_{\mathrm{mode},1F,d,t}+L_{\mathrm{mode},2F,d,t}>0\\[8pt]
0, & \text{otherwise}
\end{cases}
```

```math
\widehat{Q}_{1F,d,t}
=\widehat{Q}_{d,t}\,r_{L,1F,d,t}
```

これにより、1階の実際の時刻別負荷に応じた風量を計算できる。1月1日1時の
暖房では、12室負荷から得られる1階比率は約0.59246であり、固定面積比とは
異なる。

床下から外気・地盤への熱移動を加えた補正出力は、概念的に次の収支となる。

```math
\widehat{Q}_{H,\mathrm{corrected}}
=\widehat{Q}_{H,\mathrm{base}}
-Q_{\mathrm{floor,old}}
+Q_{\mathrm{uf\to ex}}
+Q_{\mathrm{uf\to ground}}
```

```math
\widehat{Q}_{C,\mathrm{corrected}}
=\max\left(
\widehat{Q}_{C,\mathrm{base}}
+Q_{\mathrm{floor,old}}
-Q_{\mathrm{uf\to ex}}
-Q_{\mathrm{uf\to ground}},
0
\right)
```

## 5. 変更点2：式 (52)―負荷バランス時の非居室温度

式 (52)では、非居室全体の外皮・換気熱収支と、1階床下から非居室へ伝わる
床貫流を同時に扱う。ただし両者が対象とする面積は異なる。

非居室の外皮・換気・間仕切をまとめた係数を $K_1$ とする。

```math
K_1
=K_{\mathrm{envelope}}\!\left(A_{\mathrm{NR}}=38.93\right)
+K_{\mathrm{local\ vent}}
+\sum_i
\left(
\frac{\rho c_p V_i}{3600}
+U_{\mathrm{prt}}A_{\mathrm{prt},i}
\right)
```

床下から1階非居室への床貫流係数を $K_2$ とする。

```math
K_2
=U_sA_{\mathrm{NR},1F}
=2.223\times19.04
=42.32592\ \mathrm{W/K}
```

暖房時と冷房時の負荷バランス温度は次のとおりである。

```math
\theta_{\mathrm{NR}}^{*}
=
\frac{
K_1\theta_{\mathrm{HBR}}^{*}
+K_2\theta_{\mathrm{uf}}
-\sum_iL_{H,i}\,10^6/3600
}{
K_1+K_2
}
\qquad\text{(暖房)}
```

```math
\theta_{\mathrm{NR}}^{*}
=
\frac{
K_1\theta_{\mathrm{HBR}}^{*}
+K_2\theta_{\mathrm{uf}}
+\sum_iL_{CS,i}\,10^6/3600
}{
K_1+K_2
}
\qquad\text{(冷房)}
```

外皮・換気は非居室全体38.93 m²に作用する。一方、床下貫流は床下に接する
1階非居室19.04 m²だけに作用する。この物理境界の違いを保つため、両面積を
一つの按分値へまとめない。

## 6. 変更点3：式 (8)/(9)―元負荷から今回方式の負荷への変換

### 元負荷に含まれる床損失

元の温熱シミュレーションでは、床下を外部側とみなし、断熱床を通る熱移動が
住宅負荷へ含まれている。今回の方式では床下から室へ熱を供給するため、
元負荷に含まれる床熱移動をいったん取り除く。

```math
\Delta L_{\mathrm{floor},i}
=U_{s,\mathrm{vert}}A_{\mathrm{uf},i}
\left(
\theta_{\mathrm{HBR}}^{*}-\theta_{\mathrm{ex}}
\right)
H_{\mathrm{floor}}
\frac{3.6}{1000}
```

ここで、

```math
U_{s,\mathrm{vert}}=0.5422264459110593,\qquad
H_{\mathrm{floor}}=0.7
```

である。床下から室への実熱移動に使う $U_s=2.223$ は、この取消し計算には
使用しない。

### 暖房・冷房の採用式

$Q_{\mathrm{trs,prt},i}$と$\Delta L_{\mathrm{floor},i}$は、いずれも
居室から相手側へ流出する向きを正とする。

```math
L^{*}_{H,i}
=\max\left(
L_{H,i}
+Q_{\mathrm{trs,prt},i}
-\Delta L_{\mathrm{floor},i},
0
\right)
```

```math
L^{*}_{CS,i}
=\max\left(
L_{CS,i}
-Q_{\mathrm{trs,prt},i}
+\Delta L_{\mathrm{floor},i},
0
\right)
```

冷房側では、4-2仕様書式 (9-2)の $+Q_{\mathrm{trs,prt}}$ と、修正前
Excel床下13の $-\Delta L_{\mathrm{floor}}$ は、いずれも物理収支と逆向き
であった。このため、説明資料と熱流の正方向に基づく上式へ修正した。

この処理は、同じ熱を二重に差し引くものではない。式 (8)/(9)は
「元負荷に含まれる断熱床から外部への熱移動」を取り除き、後述の式
(46)/(48)は「今回の床下から室への実熱移動」を新たに評価する。

## 7. 変更点4：式 (21)―目標床下温度とPass 1

Pass 1では、補正後の1階居室負荷を満たす目標床下温度を求め、その温度を
成立させるために必要な熱源出口温度を、同じ時刻の熱収支から直接逆算する。

### 目標床下温度

給気の熱容量流率を $C_{\mathrm{sa}}$ とすると、目標温度は次の形となる。

```math
\theta_{\mathrm{uf,target}}
=\theta_{\mathrm{HBR}}^{*}
+\frac{
\sum_{i\in 1F}L^{*}_{H,i}\,1000
}{
C_{\mathrm{sa}}+3.6U_sA_{\mathrm{HCZ},1F}
}
\qquad\text{(暖房)}
```

```math
\theta_{\mathrm{uf,target}}
=\theta_{\mathrm{HBR}}^{*}
-\frac{
\sum_{i\in 1F}L^{*}_{CS,i}\,1000
}{
C_{\mathrm{sa}}+3.6U_sA_{\mathrm{HCZ},1F}
}
\qquad\text{(冷房)}
```

ここでは、空調対象の1階居室が負荷を満たすための目標なので
$A_{\mathrm{HCZ},1F}=46.37\ \mathrm{m^2}$を使う。

### 床下全体の熱収支

床下は一体空間なので、室側、外気側、地盤側を含む床下全体の収支では
$A_{\mathrm{uf},A}=65.41\ \mathrm{m^2}$を使う。

```math
K_1=U_sA_{\mathrm{uf},A}H^{*}
```

```math
K_2=\psi L_{\mathrm{uf}}
```

```math
K_3=\frac{A_{\mathrm{uf},A}}{R_g+\varphi_{A,0}}
```

```math
K=K_1+K_2+K_3
```

```math
P
=K_1\theta_{\mathrm{HBR}}^{*}
+K_2\theta_{\mathrm{ex}}
+K_3
\left(
\sum_m\theta'_{\mathrm{g,surf},A,m}
+\theta_{\mathrm{g,avg}}
\right)
```

必要熱源出口温度は二分探索ではなく、次式で直接求める。

```math
\theta_{\mathrm{req}}
=
\frac{
\theta_{\mathrm{uf,target}}
\left(C_{\mathrm{sa}}+3.6K\right)
-3.6P
}{
C_{\mathrm{sa}}
}
```

暖房では20 ℃を下限、冷房では27 ℃を上限とする。

```math
\theta_{\mathrm{req},H}
=\max\left(\theta_{\mathrm{req},H},20\right)
```

```math
\theta_{\mathrm{req},C}
=\min\left(\theta_{\mathrm{req},C},27\right)
```

この後、RAC能力や熱源出口温度の制約を適用する。

## 8. 変更点5：式 (41)―制約後のPass 2

Pass 1で得た要求温度は、機器能力によりそのまま実現できるとは限らない。
Pass 2では、能力制約後の実熱源出口温度
$\theta_{\mathrm{hs,out}}$を使い、実際の床下温度を順方向に計算する。

```math
\theta_{\mathrm{uf}}
=
\frac{
C_{\mathrm{sa}}\theta_{\mathrm{hs,out}}
+3.6P
}{
C_{\mathrm{sa}}+3.6K
}
```

Pass 1とPass 2は同じ $K$ と $P$ を使うため、熱収支の非対称はない。
異なるのは、Pass 1が目標温度から必要出口温度を逆算し、Pass 2が制約後の
実出口温度から実床下温度を順算する点だけである。

床下は一体の完全混合空間として扱うため、居室1・2へ供給する床下温度は
共通である。床下内の局所温度分布や区画別経路長は、この計算法の対象外とする。

## 9. 変更点6：式 (46)―実際の居室温度

実居室温度は、次の二つの異なる熱供給経路を含む。

1. 床下空気を室へ吹き出すことによる顕熱移動
2. 床下から床面を介して室へ伝わる熱伝導

暖房側の概念式は次のとおりである。

```math
\theta_{\mathrm{HBR},i}
=\max\left[
\theta_{\mathrm{HBR}}^{*},
\theta_{\mathrm{HBR}}^{*}
+
\frac{
\rho c_pV_i
\left(\theta_{\mathrm{uf}}-\theta_{\mathrm{HBR}}^{*}\right)
+3600U_sA_{\mathrm{uf},i}
\left(\theta_{\mathrm{uf}}-\theta_{\mathrm{HBR}}^{*}\right)
-L^{*}_{H,i}10^6
}{
\rho c_pV_i
+3600U_sA_{\mathrm{uf},i}
+3600
\left(
U_{\mathrm{prt}}A_{\mathrm{prt},i}+QA_i
\right)
}
\right]
```

冷房側では負荷の向きを反転し、基準室温を超えて低下しないよう
$\min(\theta_{\mathrm{HBR}}^{*},\ldots)$を使う。

ここで用いる床下温度は、Pass 2で求めた能力制約後の実温度である。
給気と床貫流は同じ床下温度を熱源とするが、空気移送と熱伝導という別の
物理経路なので二重計上ではない。

## 10. 変更点7：式 (48)―実際の非居室温度

最後に、1階非居室へ床下から伝わる熱と、式 (46)で求めた実居室温度による
間仕切熱移動を反映して、実非居室温度を求める。

```math
\theta_{\mathrm{NR}}
=
\frac{
K_{\mathrm{NR}}\theta_{\mathrm{NR}}^{*}
+U_sA_{\mathrm{NR},1F}\theta_{\mathrm{uf}}
-Q_{\mathrm{vent,corr}}
+\sum_i
K_{\mathrm{prt},i}
\left(
\theta_{\mathrm{HBR},i}-\theta_{\mathrm{NR}}^{*}
\right)
}{
K_{\mathrm{NR}}+U_sA_{\mathrm{NR},1F}
}
```

床下貫流項には、床下に接する1階非居室
$A_{\mathrm{NR},1F}=19.04\ \mathrm{m^2}$だけを用いる。

式 (52)は負荷補正に必要な基準状態
$\theta_{\mathrm{NR}}^{*}$、式 (48)は機器能力制約後の実状態
$\theta_{\mathrm{NR}}$を表す。この二つは同じ出力へ重ねて加算する式ではない。

床下熱収支は参照温度、式 (46)/(48)は実温度を使うため、床下側と室側の
床貫流量には小さな差が生じ得る。これは既存計算法が採用する一方向近似の
範囲であり、同一時刻内の反復計算は導入しない。

## 11. 1時刻の計算順

7つの変更を含む1時刻の評価順は次のとおりである。

```mermaid
flowchart LR
    A["12室の元負荷"] --> B["変更1<br/>式 (40)・風量"]
    B --> C["変更2<br/>式 (52)・基準非居室温度"]
    C --> D["変更3<br/>式 (8)/(9)・負荷変換"]
    D --> E["変更4<br/>目標床下温度・Pass 1"]
    E --> F["熱源能力・出口温度制約"]
    F --> G["変更5<br/>Pass 2・実床下温度"]
    G --> H["地盤応答状態を更新"]
    H --> I["変更6<br/>式 (46)・実居室温度"]
    I --> J["変更7<br/>式 (48)・実非居室温度"]
```

前時刻から引き継ぐのは地盤応答状態だけであり、同一時刻の床下温度を
$t-1$の値で代用しない。

## 12. 修正した明白な異常

床下14では、次の異常を修正してから全セルをMicrosoft Excelで再計算した。

1. 式 (40)の1階出力が、時刻別負荷比ではなく固定面積比だった。
2. 式 (9)の冷房床補正が
   $L_{CS}-Q_{\mathrm{trs,prt}}-\Delta L_{\mathrm{floor}}$だった。
3. 元負荷3セルが、数値に見える文字列として保存されていた。

4-2仕様書式 (9-2)の冷房側 $Q_{\mathrm{trs,prt}}$ の符号も、物理収支と
整合しないため仕様書側の修正対象である。
