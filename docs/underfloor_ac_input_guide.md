# 床下関連入力ガイド

## 1. この文書の目的

この文書は、Verification Platform Next の「④ 床下・空気搬送」にある床下関連項目について、
どの設定がどの計算経路と数値に影響するかを説明する。

詳細な計算式とExcel床下14との整合内容は、次の文書を参照する。

- [床下空調の7つの変更点](underfloor_ac_seven_changes.md)
- [床下計算とExcel床下14の整合結果](underfloor_ac_excel_alignment.md)
- [床下空調7変更点の数式・採用値・設計検証台帳](underfloor_ac_seven_point_design_review.md)

## 2. 計算方式と床下の利用方法

床下空調を使う場合は、①の「計算方式」で **自立** を選ぶ。TGは床下空調に対応しない。
④では、床下を熱源機からの給気経路にするかを暖房・冷房別に選ぶ。「床下換気（建研Web）」は、
外気を床下経由で導入するときの負荷補正を選ぶ項目である。表の各セルは **暖房期／冷房期** の計算経路を示す。

| 暖房時に床下空調を使用 | 冷房時に床下空調を使用 | 床下換気OFF | 床下換気ON |
|---|---|---|---|
| OFF | OFF | 通常／通常 | 床下換気／床下換気 |
| ON | OFF | 床下空調／通常 | 床下空調／床下換気 |
| OFF | ON | 通常／床下空調 | 床下換気／床下空調 |
| ON | ON | 床下空調／床下空調 | 床下空調／床下空調 |

床下空調は暖房・冷房ごとにON／OFFを選ぶ。ONの季節は床下換気の利用面積を0%、
床下空調の利用面積を100%として扱う。OFFの季節は通常の給気経路を使い、床下換気を
選んでいる場合はその負荷補正を適用する。少なくとも一方で床下空調を使う場合、
建物の床下は年間を通じて断熱区画内として扱う。地盤・基礎の物性値も暖冷房共通である。

## 3. 現在の画面構成

④「床下・空気搬送」には、次のグループがある。

| グループ | 主な入力・表示条件 |
|---|---|
| 床下換気（建研Web） | 利用のON／OFF。ONのときに床下面積割合・断熱を表示 |
| 全館空調の風量制御 | 熱源機の全体風量を設計風量に固定する |
| 床下空調 | 暖房・冷房それぞれのON／OFFと共通の補助定数の手動設定 |
| 床下空調｜補助定数 | 暖房または冷房の床下空調と手動設定がともにONのとき、地盤表面熱伝達抵抗R_g・基礎側面の線熱貫流率φを表示 |
| 建研式との比較・補正 | 冷房時の間仕切壁熱移動の符号補正・全般換気なし時の給気風量下限補正 |
| 蓄熱・過剰熱量の持ち越し | 過剰熱量の繰越。床下空調との併用不可 |

TGを選ぶと床下空調・全体風量固定・熱の繰越はOFFとなり、自立専用の設定は非表示になる。

親となるチェックがOFFのとき、その配下の入力欄は表示されない。

## 4. 床下換気（建研Web）

### 4.1 床下空間を経由して外気を導入する換気方式の利用

建研付録D系の床下換気による暖冷房負荷補正を有効にする。

床下空調を使わない季節に、外気を床下経由で導入する住宅ではONにする。
たとえば、冬に床下換気、夏に床下空調を使う場合もONにする。

### 4.2 外気が経由する床下の面積の割合

0～100%で入力する。床下換気ONかつその季節の床下空調OFFのとき、この割合を床下換気の負荷補正に使う。
床下空調ONの季節は、床下換気の利用面積を0%、床下空調の利用面積を100%として計算する。

### 4.3 床下空間の断熱

床下換気の負荷計算および助走時の床下温度条件に使用する。
床下空調では画面の状態によらず、内部で断熱区画内に固定する。

## 5. 全館空調の風量制御

「熱源機の全体風量を設計風量に固定する」は床下専用の設定ではない。
ダクト式セントラル空調機全体の風量制御に影響する。

- OFF：通常の風量制御
- ON：暖房期は設計暖房風量、冷房期は設計冷房風量に固定し、中間期は0とする

床下空調と同時に使用できるが、比較条件として固定する場合は、床下以外の
全館空調計算にも影響することに注意する。

## 6. 床下空調

### 6.1 暖房時／冷房時に床下空調を使用する

2つのチェックで、次の4通りを選べる。初期値は両方OFF。

| 運用 | 暖房時 | 冷房時 |
|---|---|---|
| 床下を使わない | OFF | OFF |
| 暖房だけ床下を使う | ON | OFF |
| 冷房だけ床下を使う | OFF | ON |
| 暖冷房とも床下を使う | ON | ON |

新JSONは `change_underfloor_temperature_H` と `change_underfloor_temperature_C` に
1（OFF）／2（ON）を保存する。季節別キーがない旧JSONは、従来の
`change_underfloor_temperature` を各季節へ引き継ぐ。季節別キーがあればそちらを優先する。
画面へ読み込んだ後は、2つの設定を個別に編集できる。

片方だけを使う場合、OFFの季節と中間期は床下への空調送風をゼロとし、床・外気・地盤との
熱収支で床下温度を求め、地盤の熱履歴を翌時刻へ引き継ぐ。両方ONの場合は従来の
Excel床下14方式（中間期の扱いを含む）を維持する。したがって、一方の運用を変えると、
地盤の熱履歴を通じてONの季節の結果も変わり得る。

ONの季節は、床下を1階の給気経路として使用し、Excel床下14に対応する次の計算を有効にする。

1. 助走および地盤応答
2. 元負荷に含まれる床熱損失の控除
3. 目標床下温度の算定
4. Pass 1による必要熱源出口温度の直接逆算
5. RAC能力・出口温度制約
6. Pass 2による実床下温度の順計算
7. 居室・非居室温度と地盤状態の更新

反復計算や、床下温度の代わりに単純な前時刻値を使う処理は行わない。
地盤応答モデル内部で必要な前時刻状態だけを逐次保持する。

### 6.2 床下空調の補助定数を手動設定する

このチェックは、ユーザーが直接変更できる2つの定数 $R_g$ と $\phi$ の採用方法を
切り替える。

| チェック | $R_g$ | $\phi$ |
|---|---|---|
| OFF（通常） | 既定値 0.15 (m²・K)/W | 地域区分と住宅の $Q$ 値から自動算定 |
| ON（検証用） | 表示されたUI入力値 | 表示されたUI入力値 |

通常の計算ではOFFを推奨する。根拠のある試験条件やExcel床下14の固定条件を
再現する場合だけONにする。

### 6.3 地盤またはそれを覆う基礎の表面熱伝達抵抗 $R_g$

$R_g$ は、床下と地盤の熱移動および地盤応答に使用する。

$$
K_g
=\frac{A_{\mathrm{uf}}/R_g}
       {1+\varphi_{A,0}/R_g}
$$

- 単位：$\mathrm{(m^2\,K)/W}$
- 既定値：0.15
- 手動設定OFF：既定値0.15を使用
- 手動設定ON：UI入力値を使用

### 6.4 基礎側面の線熱貫流率 $\phi$

$\phi$ は床下から外気への基礎側面熱損失に使用する。

$$
K_{\mathrm{ex}}=\phi L_{\mathrm{uf}}
$$

- 単位：$\mathrm{W/(m\,K)}$
- UIの初期表示値：0.846
- 手動設定OFF：地域区分と住宅の $Q$ 値から自動算定
- 手動設定ON：UI入力値を使用

## 7. 画面から入力しない自動算定値・固定採用値

### 7.1 地盤内の不易層温度 $\Theta_{g,\mathrm{avg}}$

不易層温度は、計算に使用する外気温8760時間値の年間平均として自動算定する。
地域や気象ファイルと一体で決まるため、現在のUIには編集欄を設けない。

内部JSONには後方互換のため `Theta_g_avg=15.7` が残るが、床下空調の逐次ソルバーは
この固定値を採用せず、実際の外気温系列から求めた年間平均を使用する。

### 7.2 床板の熱貫流率

床板の熱貫流率は目的により値が異なるため、単一のUI入力値を使用しない。

| 用途 | 記号 | 採用方法 |
|---|---|---|
| 元負荷に含まれる断熱床経路の控除 | $U_{s,\mathrm{load}}$ | 地域区分と住宅の $Q$ 値から付録E式(4)により算定。標準条件では約0.542226 W/(m²・K) |
| 床下から室への実際の熱移動 | $U_{s,\mathrm{supply}}$ | 付録E式(1)の固定値 2.223 W/(m²・K) |

内部JSONには後方互換のため `U_s_vert=2.223` が残るが、床下空調の逐次ソルバーは
用途別の上記2値をコード内で明示的に使い分ける。現在のUIには編集欄を設けない。

## 8. 代表的な設定例

### 8.1 床下を利用しない通常計算

| 項目 | 設定 |
|---|---:|
| 床下換気を評価する | OFF |
| 暖房時／冷房時に床下空調を使用する | 両方OFF |

### 8.2 建研方式の床下換気

| 項目 | 設定 |
|---|---:|
| 床下換気を評価する | ON |
| 外気が経由する床下の面積の割合 | 対象住宅の条件 |
| 床下空間の断熱 | 対象住宅の条件 |
| 暖房時／冷房時に床下空調を使用する | 両方OFF |

### 8.3 Excel床下14の床下空調条件

| 項目 | 設定 |
|---|---:|
| 床下換気を評価する | OFF |
| 暖房時／冷房時に床下空調を使用する | 両方ON |
| 冷房時の間仕切壁熱移動を物理的な符号へ補正する | ON |
| 補助定数を手動設定する | ON |
| $R_g$ | 0.15 (m²・K)/W |
| $\phi$ | 0.845957617838108 W/(m・K) |
| 不易層温度 | 外気温8760時間値から自動算定 |
| 元負荷控除用の床熱貫流率 | 地域区分と $Q$ 値から自動算定 |
| 床下から室への熱移動用の床熱貫流率 | 2.223 W/(m²・K) |

この表は床下関連の条件だけを示す。Excel床下14の厳密な再現には、住宅・設備・気象・負荷も
[整合結果の比較条件](underfloor_ac_excel_alignment.md#比較条件と資料)にそろえる必要がある。
φの初期表示値0.846は丸めた値なので、固定条件の再現では上記の値を使う。

### 8.4 暖房期は床下換気、冷房期は床下空調を使う例

①で「自立」を選び、④で「床下空間を経由して外気を導入する換気方式の利用」をONにする。
「暖房時に床下空調を使用する」はOFF、「冷房時に床下空調を使用する」はONにする。

- 暖房期は通常の空調給気経路を使う。外気が経由する床下の面積割合を④に入力すると、暖房負荷に床下換気の補正が反映される。
- 冷房期は熱源機の空気を1階床下に送る。床下換気の補正は重ねて適用しない。床下空調を使う季節があるため、床下の断熱条件は年間を通じて断熱区画内となる。

計算後、「計算入力」で `change_underfloor_temperature_H` が `"1"`、`change_underfloor_temperature_C` が `"2"` であることを確認できる。

## 9. 同時に使用できない設定

TGと床下空調は併用できない。画面でTGへ切り替えると床下空調はOFFとなり、
JSONで同時に指定した場合も計算開始前にエラーとなる。

暖房・冷房のどちらかで床下空調を使う場合、「過剰熱量持越し」とは併用できない。
両方をONにすると、計算開始時に次のエラーを表示する。

```text
床下空調と過剰熱量繰越計算は同時に使用できません。
どちらか一方を無効にしてください。
```

削除済みの旧入力 `underfloor_air_conditioning_air_supply=2` をJSONから直接指定する
こともできない。床下空調は画面の「暖房時／冷房時に床下空調を使用する」から選択する。

## 10. 計算後の確認

計算後は次を確認する。

1. 「計算入力」タブに、選択したチェックと手動値が反映されていること
2. 「計算ログ」に「床下空調ロジックを使用」と表示されること
3. 暖房・冷房の年間結果と時系列出力が比較条件と一致していること
4. 手動設定した場合は、`R_g` と `phi` が保存された入力JSONに入っていること

不易層温度と床板熱貫流率はUI入力ではない。これらを確認するときは、気象ファイル、
地域区分、$Q$ 値、および計算ログ・時系列出力を確認する。

## 11. 入力判断に迷った場合

通常は次の順で判断する。

1. 暖房期と冷房期のそれぞれについて、床下を空調給気経路として使うか決める。
2. 床下空調を使わない季節に外気を床下経由で導入するなら、床下換気をONにして面積割合を入力する。
3. 床下空調を使う場合、$R_g$ と $\phi$ を既定・自動値から変更する根拠があるか
4. 全体風量を設計風量に固定する比較条件か

数式や採用値を変更する必要がある場合は、この入力ガイドだけで判断せず、
床下空調の設計文書とExcel整合結果を参照し、数値回帰への影響を確認する。
