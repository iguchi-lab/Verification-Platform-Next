# 床下関連入力ガイド

## 1. この文書の目的

この文書は、Verification Platform Next の「④ 床下・空気搬送」にある床下関連項目について、
どの設定がどの計算経路と数値に影響するかを説明する。

詳細な計算式とExcel床下14との整合内容は、次の文書を参照する。

- [床下空調の7つの変更点](underfloor_ac_seven_changes.md)
- [床下計算とExcel床下14の整合結果](underfloor_ac_excel_alignment.md)
- [床下空調7変更点の数式・採用値・設計検証台帳](underfloor_ac_seven_point_design_review.md)

## 2. 最初に選ぶ計算方式

床下に関係する計算方式は次の3通りである。

| 計算したい内容 | 「床下空間を経由して外気を導入する換気方式の利用」 | 「床下空調を使用する」 | 計算経路 |
|---|---:|---:|---|
| 床下を利用しない通常計算 | OFF | OFF | 床下関連の補正を行わない |
| 建研方式の床下換気 | ON | OFF | 外気を床下経由で導入することによる負荷補正 |
| 床下を空調給気経路として使用 | OFF | ON | Excel床下14に対応するPass 1・Pass 2・地盤逐時計算 |

「床下換気（建研Web）」と「床下空調」は別の計算である。

- 床下換気は、外気を床下経由で導入する換気方式を評価する。
- 床下空調は、熱源機からの空調空気を1階床下へ送り、床下から居室・非居室へ
  移動する熱を評価する。

床下空調をONにすると、内部では床下換気の利用面積を0%、床下空調の利用面積を
100%、床下空間を断熱区画内として扱う。したがって、床下換気側の面積割合と
断熱チェックは床下空調の条件設定には使用しない。

## 3. 現在の画面構成

```text

├─ 床下換気（建研Web）
│  ├─ 床下空間を経由して外気を導入する換気方式の利用
│  └─ ONのときだけ表示
│     ├─ 外気が経由する床下の面積の割合
│     └─ 床下空間の断熱
│
├─ 全館空調の風量制御
│  └─ 熱源機の全体風量を設計風量に固定する
│
├─ 床下空調
│  ├─ 床下空調を使用する
│  └─ ONのときだけ表示
│     ├─ 床下空調の補助定数を手動設定する
│     └─ 手動設定ONのときだけ表示
│        ├─ 地盤表面熱伝達抵抗 R_g
│        └─ 基礎側面の線熱貫流率 φ
│     （チェック項目の説明文に、不易層温度と床板熱貫流率の
│      自動算定・固定採用方法を表示）
│
└─ 建研式との比較・補正
   ├─ 冷房時の間仕切壁熱移動を物理的な符号へ補正する
   └─ 全般換気なし時の給気風量下限を補正する
```

親となるチェックがOFFのとき、その配下の入力欄は表示されない。

## 4. 床下換気（建研Web）

### 4.1 床下空間を経由して外気を導入する換気方式の利用

建研付録D系の床下換気による暖冷房負荷補正を有効にする。

- 通常計算：OFF
- 外気を床下経由で導入する換気方式：ON
- 床下空調：OFF

### 4.2 外気が経由する床下の面積の割合

床下換気をONにした場合だけ使用する。入力範囲は0～100%である。
床下空調の床下利用面積ではない。床下空調をONにした場合は内部で100%に固定する。

### 4.3 床下空間の断熱

床下換気の負荷計算および助走時の床下温度条件に使用する。
床下空調では画面の状態によらず、内部で断熱区画内に固定する。

## 5. 全館空調の風量制御

「熱源機の全体風量を設計風量に固定する」は床下専用の設定ではない。
ダクト式セントラル空調機全体の風量制御に影響する。

- OFF：通常の風量制御
- ON：暖房期は設計暖房風量、冷房期は設計冷房風量に固定し、中間期は0とする

床下空調と同時に使用できるが、比較条件として固定する場合は、床下以外の
全館空調計算にも影響することに注意する。

## 6. 床下空調

### 6.1 床下空調を使用する

床下を1階の給気経路として使用し、Excel床下14に対応する次の計算を有効にする。

1. 助走および地盤応答
2. 元負荷に含まれる床熱損失の控除
3. 目標床下温度の算定
4. Pass 1による必要熱源出口温度の直接逆算
5. RAC能力・出口温度制約
6. Pass 2による実床下温度の順計算
7. 居室・非居室温度と地盤状態の更新

反復計算や、床下温度の代わりに単純な前時刻値を使う処理は行わない。
地盤応答モデル内部で必要な前時刻状態だけを逐次保持する。

### 6.2 床下空調の補助定数を手動設定する

このチェックは、ユーザーが直接変更できる2つの定数 $R_g$ と $\phi$ の採用方法を
切り替える。

| チェック | $R_g$ | $\phi$ |
|---|---|---|
| OFF（通常） | 既定値 0.15 (m²・K)/W | 地域区分と住宅の $Q$ 値から自動算定 |
| ON（検証用） | 表示されたUI入力値 | 表示されたUI入力値 |

通常の計算ではOFFを推奨する。根拠のある試験条件やExcel床下14の固定条件を
再現する場合だけONにする。

### 6.3 地盤またはそれを覆う基礎の表面熱伝達抵抗 $R_g$

$R_g$ は、床下と地盤の熱移動および地盤応答に使用する。

$$
K_g
=\frac{A_{\mathrm{uf}}/R_g}
       {1+\varphi_{A,0}/R_g}
$$

- 単位：$\mathrm{(m^2\,K)/W}$
- 既定値：0.15
- 手動設定OFF：既定値0.15を使用
- 手動設定ON：UI入力値を使用

### 6.4 基礎側面の線熱貫流率 $\phi$

$\phi$ は床下から外気への基礎側面熱損失に使用する。

$$
K_{\mathrm{ex}}=\phi L_{\mathrm{uf}}
$$

- 単位：$\mathrm{W/(m\,K)}$
- UIの初期表示値：0.846
- 手動設定OFF：地域区分と住宅の $Q$ 値から自動算定
- 手動設定ON：UI入力値を使用

## 7. 画面から入力しない自動算定値・固定採用値

### 7.1 地盤内の不易層温度 $\Theta_{g,\mathrm{avg}}$

不易層温度は、計算に使用する外気温8760時間値の年間平均として自動算定する。
地域や気象ファイルと一体で決まるため、現在のUIには編集欄を設けない。

内部JSONには後方互換のため `Theta_g_avg=15.7` が残るが、床下空調の逐次ソルバーは
この固定値を採用せず、実際の外気温系列から求めた年間平均を使用する。

### 7.2 床板の熱貫流率

床板の熱貫流率は目的により値が異なるため、単一のUI入力値を使用しない。

| 用途 | 記号 | 採用方法 |
|---|---|---|
| 元負荷に含まれる断熱床経路の控除 | $U_{s,\mathrm{load}}$ | 地域区分と住宅の $Q$ 値から付録E式(4)により算定。標準条件では約0.542226 W/(m²・K) |
| 床下から室への実際の熱移動 | $U_{s,\mathrm{supply}}$ | 付録E式(1)の固定値 2.223 W/(m²・K) |

内部JSONには後方互換のため `U_s_vert=2.223` が残るが、床下空調の逐次ソルバーは
用途別の上記2値をコード内で明示的に使い分ける。現在のUIには編集欄を設けない。

## 8. 代表的な設定例

### 8.1 床下を利用しない通常計算

| 項目 | 設定 |
|---|---:|
| 床下換気を評価する | OFF |
| 床下空調を使用する | OFF |

### 8.2 建研方式の床下換気

| 項目 | 設定 |
|---|---:|
| 床下換気を評価する | ON |
| 外気が経由する床下の面積の割合 | 対象住宅の条件 |
| 床下空間の断熱 | 対象住宅の条件 |
| 床下空調を使用する | OFF |

### 8.3 Excel床下14の床下空調条件

| 項目 | 設定 |
|---|---:|
| 床下換気を評価する | OFF |
| 床下空調を使用する | ON |
| 冷房時の間仕切熱移動を物理的な符号に補正する | ON |
| 補助定数を手動設定する | ON |
| $R_g$ | 0.15 (m²・K)/W |
| $\phi$ | 0.846 W/(m・K) |
| 不易層温度 | 外気温8760時間値から自動算定 |
| 元負荷控除用の床熱貫流率 | 地域区分と $Q$ 値から自動算定 |
| 床下から室への熱移動用の床熱貫流率 | 2.223 W/(m²・K) |

## 9. 同時に使用できない設定

床下空調と「過剰熱量持越し」の過剰熱量繰越計算は同時に使用できない。
両方をONにすると、計算開始時に次のエラーを表示する。

```text
床下空調と過剰熱量繰越計算は同時に使用できません。
どちらか一方を無効にしてください。
```

削除済みの旧入力 `underfloor_air_conditioning_air_supply=2` をJSONから直接指定する
こともできない。床下空調は画面の「床下空調を使用する」から選択する。

## 10. 計算後の確認

計算後は次を確認する。

1. 「計算入力」タブに、選択したチェックと手動値が反映されていること
2. 「計算ログ」に「床下空調ロジックを使用」と表示されること
3. 暖房・冷房の年間結果と時系列出力が比較条件と一致していること
4. 手動設定した場合は、`R_g` と `phi` が保存された入力JSONに入っていること

不易層温度と床板熱貫流率はUI入力ではない。これらを確認するときは、気象ファイル、
地域区分、$Q$ 値、および計算ログ・時系列出力を確認する。

## 11. 入力判断に迷った場合

通常は次の順で判断する。

1. 床下を空調給気経路として使うか
2. 使わない場合、建研方式の床下換気を評価するか
3. 床下空調を使う場合、$R_g$ と $\phi$ を既定・自動値から変更する根拠があるか
4. 全体風量を設計風量に固定する比較条件か

数式や採用値を変更する必要がある場合は、この入力ガイドだけで判断せず、
床下空調の設計文書とExcel整合結果を参照し、数値回帰への影響を確認する。
