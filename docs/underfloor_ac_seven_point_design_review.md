# 床下空調 7 変更点の数式・採用値・設計検証台帳

## 目的

`260713_説明資料.pptx` の 1 枚目に示された 7 変更点について、
Excel 床下14、仕様書、Verification Platform の関係を一項目ずつ検証する。
床下14は床下13を保存してから、確定した負荷按分と式 (9)を修正し、
Excel本体で全再計算した検証版である。

この文書は、Excel との一致結果を記録した
`docs/underfloor_ac_excel_alignment.md` を置き換えるものではない。
同文書で Excel 表示桁の一致を確認した計算について、次の問いを改めて扱う。

1. 数式の熱収支と単位は成立しているか。
2. 面積、熱貫流率、温度差係数などの値の選び方は妥当か。
3. 同じ熱移動を別の式で二重に加算・控除していないか。
4. Excel に数式、参照、コピー、分岐上の異常がないか。
5. Excel と仕様書が異なる場合、どちらを最終仕様とするか。

## 計算全体の読み方

1時刻の計算は、次の因果順で一度だけ評価する。

```text
12室の元負荷
  -> 式 (40): 1F負荷按分、床下から外気・地盤への損失補正
  -> VAV調整前風量
  -> 式 (52): 負荷バランス時の非居室温度
  -> 式 (8)/(9): 元の断熱床損失を除いた居室負荷
  -> 目標床下温度
  -> Pass 1: 必要熱源出口温度の直接逆算
  -> 熱源能力・出口温度制約
  -> Pass 2: 制約後出口温度から実床下温度を順計算
  -> 地盤応答状態の更新
  -> 式 (46)/(48): 実居室温度・実非居室温度
```

反復計算、二分探索、`t-1`の床下温度による代用は行わない。前時刻から
引き継ぐのは、付録 E 式 (9)～(12)で定義された地盤応答の内部状態だけである。

熱移動の正方向は次のように統一する。

| 熱移動 | 正方向 | 主な使用箇所 |
| --- | --- | --- |
| `Q_trs_prt` | 居室から非居室 | 式 (8)/(9) |
| `delta_L_floor` | 元負荷の居室から外部相当 | 式 (8)/(9) |
| 床下・室間の床貫流 | 床下から居室・非居室 | 床下熱収支、式 (46)/(48) |
| `Q_uf_to_ex` | 床下から外気 | 式 (40)、床下熱収支 |
| `Q_uf_to_ground` | 床下から地盤 | 式 (40)、付録 E 地盤応答 |

床下側で損失として計上した床貫流を、室側で取得熱として計上するのは
エネルギー保存の両側を表すものであり、二重計上ではない。

## 負荷の出自と二つの区画集合

この計算には、次の二つの異なる区画集合がある。両者を混同しない。

1. **ダクト式全館空調の空調対象**: 暖冷房区画 `i=1～5`
2. **階別負荷按分の参照負荷**: 全室を設定温度とした別の温熱シミュレーションの
   暖冷房区画 `i=1～12`

参照負荷は、別の温熱シミュレーションでは全館空調を直接計算できないため、
全ての部屋を設定温度に保った場合の複数の計算値を組み合わせて作られている。
したがって、式 (40) の階別按分では空調対象 `i=1～5` だけを集計せず、
非居室を含む12区画を次のように階別集計する。

| `i` | 室 | 階 | ダクト式空調の空調対象 | 階別負荷按分に使用 |
| ---: | --- | --- | --- | --- |
| 1 | 居間食堂・台所 | 1F | 対象 | 1F負荷 |
| 2 | 和室 | 1F | 対象 | 1F負荷 |
| 3 | 主寝室 | 2F | 対象 | 2F負荷 |
| 4 | 子供室1 | 2F | 対象 | 2F負荷 |
| 5 | 子供室2 | 2F | 対象 | 2F負荷 |
| 6 | 浴室 | 1F | 対象外 | 1F負荷 |
| 7 | 1F便所 | 1F | 対象外 | 1F負荷 |
| 8 | 洗面所 | 1F | 対象外 | 1F負荷 |
| 9 | ホール | 1F | 対象外 | 1F負荷 |
| 10 | クローゼット | 2F | 対象外 | 2F負荷 |
| 11 | 2Fホール | 2F | 対象外 | 2F負荷 |
| 12 | 2F便所 | 2F | 対象外 | 2F負荷 |

```text
I_1F = {1, 2, 6, 7, 8, 9}
I_2F = {3, 4, 5, 10, 11, 12}

L_mode,1F(d,t) = sum_i in I_1F L_mode(d,t,i)
L_mode,2F(d,t) = sum_i in I_2F L_mode(d,t,i)

r_L,1F(d,t) =
  L_mode,1F(d,t) / (L_mode,1F(d,t) + L_mode,2F(d,t))
```

暖房では `L_mode=L_H`、冷房では `L_mode=L_CS` とする。分母が0の時刻は、
按分対象となる負荷がないため `r_L,1F=0` とする。

## 7 変更点

### ① 式 (40): 風量計算用の熱源機出力

**設計意図**

従来の熱源出力から、すでに見込んでいた床損失を控除し、床下から外気・
地盤への実際の損失を加えて、風量計算用の熱源出力を補正する。

**採用する主要式**

修正前のExcel床下13は、1F分の熱源出力を次の床面積比で算出していた。

```text
Q_hat_1F = Q_hat * A_HCZ,1F / (A_HCZ,1F + A_HCZ,2F)
          = Q_hat * 46.37 / (46.37 + 34.78)
```

Excel床下14とコードは、説明資料と今回確認した負荷の出自に従い、
次の時刻別負荷按分を使用する。

```text
Q_hat_1F(d,t) = Q_hat(d,t) * r_L,1F(d,t)
```

床下温度の一次推定は、暖房を例にすると次の形である。

```text
theta_uf,1 =
  theta_HBR_star
  + (Q_hat_1F * 1000 - Q_floor,old)
    / (rho * c_p * V_1F / 1000 + 3.6 * U_s * A_HCZ,1F)
```

補正後出力は次の熱収支である。

```text
暖房:
Q_hat_corrected =
  Q_hat_base - Q_floor,old + Q_uf_to_ex + Q_uf_to_ground

冷房:
Q_hat_corrected =
  max(Q_hat_base + Q_floor,old - Q_uf_to_ex - Q_uf_to_ground, 0)
```

代表セルは `床下計算①!E6:T8765`、結合結果は `負荷計算!CG5:CG8764`。

**現在の採用判断**

- 1F出力は12区画の時刻別負荷比で按分する。
- 空調対象 `i=1～5` と、負荷按分に使う全室 `i=1～12` を区別する。
- Excel床下14で固定面積按分を時刻別負荷按分へ修正済み。
- 地盤応答、暖冷房の符号と評価順は採用確定。
- 冷房側の負出力は `max(..., 0)` で制限する。

**物理・Excel 異常候補**

説明資料 4 枚目には「`L_H,1F` は面積按分でなく負荷按分に変更」とあるが、
修正前Excel床下13の`床下計算①!E6`は床面積比で按分していた。
床下14では同セルを、暖房`M:X`、冷房`Y:AJ`の12室負荷から
`I_1F={1,2,6,7,8,9}`を毎時集計する式へ修正した。

面積按分比は年間を通じて `0.5714109673` で固定される。一方、コードで再現した
12区画負荷から算出した1F負荷比は次のように時刻変動する。

| モード | 有効時刻 | 負荷比平均 | 最小 | 最大 | 固定面積比との差の平均絶対値 |
| --- | ---: | ---: | ---: | ---: | ---: |

| 冷房顕熱 | 2351 | 0.7014691173 | 0.1335336623 | 1 | 0.1748996998 |

### ② 式 (52): 負荷バランス時の非居室温度

**設計意図**

非居室の熱収支へ、床下から 1F 非居室床を通る貫流熱を追加する。

**Excel の主要式**

```text
K_1 =
  K_envelope(A_NR=38.93)
  + K_local_vent
  + sum_i(rho * c_p * V_i / 3600 + U_prt * A_prt_i)

K_2 = U_s * A_NR,1F
    = 2.223 * 19.04
    = 42.32592 W/K

暖房:
theta_NR_star =
  (K_1 * theta_HBR_star + K_2 * theta_uf - sum(L_H) * 10^6 / 3600)
  / (K_1 + K_2)

冷房:
theta_NR_star =
  (K_1 * theta_HBR_star + K_2 * theta_uf + sum(L_CS) * 10^6 / 3600)
  / (K_1 + K_2)
```

代表セルは `床下計算②!E6:T8765`、結合結果は `負荷計算!CP5:CP8764`。

**現在の採用判断**

- 外皮・換気項は非居室全体 38.93 m2。
- 床下貫流項だけ 1F 非居室 19.04 m2。
- 両面積を一つの比率へまとめず、別の物理境界として採用する。
- 1Fホール13.25 m2のうち玄関部分には床下がないため、床下空間に接する
  10.76 m2だけを床下貫流項へ含める。

**付録 E による根拠**

`3-1_260401_v20 (1).pdf`、Ver.20（2026.04）、付録 E、
3-1-45ページの「表 E.6 暖冷房区画 i の床面積のうち床下空間に接する
床面積の割合 r_A,uf,i」による。

表 E.6では、区画1、2、6、7、8は割合1.0、区画3、4、5、10、11、12は
割合0、区画9のホールは次の割合と定められている。

```text
r_A,uf,9 = 10.76 / 13.25
```

したがって、1F非居室の床下接触面積は次のとおりである。

```text
A_NR,1F
  = 3.31 * 1.0
  + 1.66 * 1.0
  + 3.31 * 1.0
  + 13.25 * (10.76 / 13.25)
  = 19.04 m2
```

ホール全体13.25 m2との差2.49 m2が、床下のない玄関部分に相当する。
居室1、2も含めた床下接触面積合計は次のとおりである。

```text
A_s,ufvnt,A = 29.81 + 16.56 + 19.04 = 65.41 m2
```

### ③ 式 (8)/(9): 熱損失を含む負荷バランス時の暖冷房負荷

**設計意図**

従来負荷ですでに見込まれた「床を通して外部へ逃げる負荷」を控除し、
床下経路で別途評価する熱収支との二重計上を避ける。

元の12区画負荷を作成した別の温熱シミュレーションでは、床下は室から熱が
逃げる外部側の経路として扱われている。今回の方式では1階床下を給気経路に使い、
床下から室へ熱を供給する。このため、元負荷に含まれる床下への熱損失を
温度差係数 `H_floor=0.7` としていったん控除し、実際の床下温度による熱供給を
式 (46)/(48)側で改めて評価する。これは床経路の二重計上を避けるための
「元負荷の基準条件から今回方式の熱収支への置換」である。

**Excel の主要式**

```text
delta_L_floor_i =
  U_s,vert * A_uf_i * (theta_HBR_star - theta_ex)
  * H_floor * 3.6 / 1000

L_star_H_i =
  max(L_H_i + Q_trs_prt_i - delta_L_floor_i, 0)

L_star_CS_i =
  max(L_CS_i - Q_trs_prt_i + delta_L_floor_i, 0)
```

ここでは `U_s,vert=0.542226...`、`H_floor=0.7` を使用し、
床下から室への直接貫流に使う `U_s=2.223` とは区別する。

`Q_trs_prt_i` と `delta_L_floor_i` は、いずれも居室から相手側へ
流出する向きを正とする符号付き熱流である。一方、冷房負荷は室へ流入する
熱取得の大きさを正値で表す。このため冷房側では、非居室への流出熱を
`-Q_trs_prt_i`、元負荷から取り除く断熱床の流出熱を
`+delta_L_floor_i`として扱う。

**仕様書・説明資料・Excel の差**

| 出典 | 暖房側 | 冷房側 |
| --- | --- | --- |
| 4-2仕様書 Ver.14 式 (8)/(9) | `L_H + Q_trs` | `L_CS + Q_trs` |
| 説明資料9枚目 | `L_H + Q_trs - delta_L_floor` | `L_CS - Q_trs + delta_L_floor` |
| Excel床下13（修正前） | `L_H + Q_trs - delta_L_floor` | `L_CS - Q_trs - delta_L_floor` |
| Excel床下14（修正後） | `L_H + Q_trs - delta_L_floor` | `L_CS - Q_trs + delta_L_floor` |
| 採用式 | `L_H + Q_trs - delta_L_floor` | `L_CS - Q_trs + delta_L_floor` |

仕様書式 (11)では
`Q_trs = U_prt * A_prt * (theta_HBR_star - theta_NR_star)`である。
冷房時に非居室が居室より高温なら`Q_trs < 0`となるため、非居室からの熱取得を
冷房負荷へ加えるには`-Q_trs`とする必要がある。説明資料9枚目の
「仕様書の式が違っている模様」は、この冷房側の符号を指すと判断した。

また、外気が居室より高温なら`delta_L_floor < 0`となる。元負荷に含まれている
外部からの床熱取得を取り除くには、冷房負荷へ`+delta_L_floor`を加える必要がある。
修正前Excelと現行コードの`-delta_L_floor`は、床熱取得を取り除くのではなく
増加させるため、物理的に逆向きであった。

**二つの熱貫流率の物理的意味**

元の12区画負荷を作成した別の温熱シミュレーションは、床断熱を施した住宅を
想定している。そのため、元負荷に既計上の「室から床下・外部へ逃げる熱」を
控除する場合は、その負荷計算で使った断熱床の熱貫流率
`U_s,vert=0.5422264459110593 W/(m2 K)`を使う。

一方、今回の方式では1階床下を給気経路として使い、床下空気から床面を通して
居室・非居室へ熱を渡す。この床面は断熱しない想定であるため、実際の床下熱収支、
式 (52)、式 (46)、式 (48)には付録 E の固定値
`U_s=2.223 W/(m2 K)`を使う。

```text
元負荷に含まれる床損失の取消し:
  delta_L_floor
    = U_s,vert * A_uf * (theta_room - theta_ex)
      * H_floor * 3.6 / 1000

今回方式の床下から室への実熱移動:
  Q_uf_to_room
    = U_s * A_uf * (theta_uf - theta_room)
```

`U_s,vert`を実熱移動へ使うと床下から室への供給を過小評価し、`U_s`を元負荷の
控除へ使うと、元の温熱シミュレーションに含まれていた床損失を過大に取り消す。
したがって、両値の入替えは許容しない。

**付録 E の参照**

- 3-1-40ページ、表 E.1:
  `U_s`を「床の熱貫流率」、`U_s,vert`を
  「暖冷房負荷計算時に想定した床の熱貫流率」と定義。
- 3-1-41ページ、式 (1):
  床下温度の熱収支に `U_s`を使用し、`U_s=2.223 W/(m2 K)`と規定。
- 3-1-42ページ:
  `H_floor=0.7`と規定。
- 3-1-43ページ、式 (4)・表 E.3:
  `U_s,vert`を地域、Q、断熱性能区分から補間し、上限を2.223と規定。

**コード監査結果**

| 計算 | 使用すべき値 | コード上の値 | 判定 |
| --- | ---: | ---: | --- |
| 式 (40)で元の床損失を控除 | `U_s,vert` | `climate.get_U_s_vert(Q)` = 0.542226... | 正しい |
| 式 (8)/(9)で元負荷を補正 | `U_s,vert` | `u_s_load` = 0.542226... | 正しい |
| Pass 1/2の床下熱収支 | `U_s` | `u_s_supply` = 2.223 | 正しい |
| 式 (52)の床下・非居室貫流 | `U_s` | `get_U_s()` = 2.223 | 正しい |
| 式 (46)の床下・居室貫流 | `U_s` | `get_U_s()` = 2.223 | 正しい |
| 式 (48)の床下・非居室貫流 | `U_s` | `get_U_s()` = 2.223 | 正しい |

外部入力名`U_s_vert`は、画面上では床板上面の`U_s=2.223`を表していた一方、
`ClimateService.get_U_s_vert()`も同名であったため、明示定数入力時に
`2.223`が元負荷控除側へ流れる潜在的な取り違いがあった。この経路は修正し、
`get_U_s_vert(Q)`が常に付録 E 式 (4)から算定するよう固定した。

代表セルは `床下計算③!E6:H8765`、結合結果は
`負荷計算!DE:DF` と `DL:DM`。

**現在の採用判断**

- 元負荷に含まれる床下への熱損失を `H_floor=0.7` で控除する考え方を採用する。
- 控除対象は元の温熱シミュレーションで既計上の床損失であり、今回の床下から
  室への実熱供給とは別項として扱う。
- 冷房側は説明資料9枚目と物理収支に従い、
  `L_CS - Q_trs + delta_L_floor`を採用する。
- `max(..., 0)`は、全補正項を合成した後に適用する。
- 仕様書式 (9-2)の`+Q_trs`は誤り、修正前Excelの
  `-delta_L_floor`も誤りと判断する。

**異常判定**

- 仕様書式 (9-2): **仕様書修正推奨**
- 修正前Excel `床下計算③!G6:H8765`: **Excel修正推奨**
- 修正前コードの冷房床補正: **コード修正**

### ④ 式 (21): 熱源出口の要求空気温度（Pass 1）

**設計意図**

補正後負荷から目標床下温度を求め、その温度を成立させる熱源出口温度を
床下熱収支の直接逆算で求める。

**Excel の主要式**

```text
暖房目標:
theta_uf,target =
  theta_HBR_star
  + sum(L_star_H_1F) * 1000
    / (C_sa + 3.6 * U_s * A_HCZ,1F)

冷房目標:
theta_uf,target =
  theta_HBR_star
  - sum(L_star_CS_1F) * 1000
    / (C_sa + 3.6 * U_s * A_HCZ,1F)
```

床下全体の損失係数を次のように置く。

```text
K_1 = U_s * A_s,ufvnt,A * H_star
K_2 = psi * L_uf
K_3 = A_s,ufvnt,A / (R_g + phi_A,0)
K = K_1 + K_2 + K_3

P = K_1 * theta_HBR_star
  + K_2 * theta_ex
  + K_3 * (sum(theta'_g,surf,A) + theta_g,avg)
```

要求熱源出口温度は次の直接逆算である。

```text
theta_req =
  (theta_uf,target * (C_sa + 3.6 * K) - 3.6 * P) / C_sa

暖房: theta_req = max(theta_req, 20)
冷房: theta_req = min(theta_req, 27)
```

代表セルは `床下計算④!G6:S8765`。

**面積境界の確定**

床下は区画ごとに分割せず、一つの完全混合空間として一つの床下温度
`theta_uf`を持つものとする。一方、床下から上階への床貫流は、熱を受ける
室の用途に応じて次の二つに分ける。

```text
A_s,ufvnt,A
  = A_HCZ,1F + A_NR,1F
  = 46.37 + 19.04
  = 65.41 m2
```

- `A_HCZ,1F=46.37 m2`は、空調対象となる1F居室（区画1、2）が床下から
  直接受ける熱の面積である。目標床下温度は、補正後の1F居室負荷を満たす
  制御目標なので、この面積だけを使う。
- `A_NR,1F=19.04 m2`は、1F非居室が床下から熱を受ける面積である。
  非居室は空調対象居室ではないため、目標床下温度の居室負荷項には加えないが、
  床下全体の熱収支からは除外しない。
- `A_s,ufvnt,A=65.41 m2`は、一体の床下空間に接する床面積の合計である。
  室側への床貫流、地盤応答、基礎外周長を含む床下全体の熱収支に使う。

この使い分けは、付録 E 3-1-41ページの式 (1)が室ごとの
`U_s A_s,ufvnt,i H_i*`を合計し、地盤項には合計面積
`A_s,ufvnt,A`を使う構造、ならびに3-1-45ページの式 (8)・表 E.6と一致する。
今回の条件では参照温度と参照温度差係数が各1F室で共通なので、Excelでは
室側の合計も`U_s * 65.41 * H*`へ集約されている。

Excel床下14では、`床下定数!E19:E21`に65.41、46.37、19.04 m2を保持し、
`床下計算④!F6:F8765`の目標温度係数には46.37 m2、
`床下計算④!I6:K8765`の床下全体係数には65.41 m2を使用している。
コードも同じ境界であり、面積値または式の修正は不要である。

**現在の採用判断**

- 二分探索は使わず、Excel の直接逆算を採用。
- `t-1` の床下温度は代用しない。
- 前時刻状態は付録 E の地盤応答モデル内部だけで保持する。
- 20 C / 27 C の制限と熱源能力制約の適用順を採用確定。
- 目標床下温度には1F居室46.37 m2、床下全体の熱収支には1F居室と
  1F非居室を合わせた65.41 m2を使う。

**確認結果**

- 65.41 m2の室側床貫流項と、式 (52)/(48)で求める非居室への床貫流が、
  全体系の負荷・温度計算で重複していないことをA-07で確認した。
- `C_sa=0` または非常に小さい無負荷時刻の扱いは、Excel 数式だけでは
  安全性が明示されない。コードは負荷・風量分岐で除外している。

状態: **面積境界は確認済み**

### ⑤ 式 (41): 暖冷房区画の吹出温度（Pass 2）

**設計意図**

能力制約後の実熱源出口温度から、床下熱収支を順方向に解き、居室へ届く
実際の供給温度を求める。

**Excel の主要式**

```text
theta_supply =
  [C_sa * theta_hs_out
   + 3.6 * {
       K_1 * theta_HBR_star
       + K_2 * theta_ex
       + K_3 * (sum(theta'_g,surf,A) + theta_g,avg)
     }]
  / [C_sa + 3.6 * (K_1 + K_2 + K_3)]
```

代表セルは `床下計算⑤!P6:P8765`、結合結果は
`負荷計算!FM5:FN8764`。

**現在の採用判断**

- Pass 1 と同じ係数・地盤応答項を使う。
- 能力制約前の要求温度ではなく、制約後の `theta_hs_out` を使う。
- 居室 1、2には共通床下空間の同じ供給温度を出力する。
- 床下は一体の完全混合空間であり、区画別の負荷・床面積は分けても、
  床下温度自体は区画別に分けない。

**モデル化範囲**

- 居室 1、2に同じ温度を与えることは、今回確認した一体床下の設計意図と
  一致する。
- 床下内の局所温度分布、経路長、漏気、および床下出口後の区画別追加熱損失は
  モデル化しない。これらを将来扱う場合は、一体床下の熱収支とは別の下流境界
  として追加する。

状態: **確認済み**

### ⑥ 式 (46): 暖冷房区画の実際の居室温度

**設計意図**

従来の給気による熱供給に加え、床下から床を通る直接熱供給を居室熱収支へ
追加し、実際の居室温度を求める。

**Excel の主要式**

暖房側を概念式で表す。

```text
theta_HBR_i =
  max[
    theta_HBR_star,
    theta_HBR_star
    + {
        rho * c_p * V_i * (theta_supply - theta_HBR_star)
        + 3600 * U_s * A_uf_i
          * (theta_uf - theta_HBR_star)
        - L_star_H_i * 10^6
      }
      / {
        rho * c_p * V_i
        + 3600 * U_s * A_uf_i
        + 3600 * (U_prt * A_prt_i + Q * A_i)
      }
  ]
```

冷房側は負荷符号を反転し、`min(theta_HBR_star, ...)` を使う。
代表セルは `床下計算⑥!E6:H8765`、結合結果は
`負荷計算!FT5:FU8764`。

**現在の採用判断**

- Pass 2 後の実供給温度を使用する。
- 暖房は基準室温以上、冷房は基準室温以下へ制限する。
- 給気と床貫流を別の熱供給経路として採用する。

**A-07の解釈**

- 式 (8)/(9)は元負荷に含まれる断熱床から外部への熱移動を取り除き、
  式 (46)は床下から居室への実際の熱移動を新たな境界条件として加える。
  同じ熱の二重計上ではなく、旧床境界から新床境界への置き換えである。
- `theta_supply` と `theta_uf` が同じ系列であるため、空気経路と貫流経路の
  二つの項は同じ温度源を持つが、給気による顕熱移動と床を介する熱伝導という
  異なる熱移動経路である。

状態: **確認済み**

### ⑦ 式 (48): 実際の非居室温度

**設計意図**

非居室の実熱収支へ、1F 非居室床を通る床下からの供給と、実居室温度による
間仕切熱移動の変化を反映する。

**Excel の主要式**

```text
theta_NR =
  {
    K_NR * theta_NR_star
    + U_s * A_NR,1F * theta_supply
    - Q_vent_correction
    + sum_i[K_prt_i * (theta_HBR_i - theta_NR_star)]
  }
  / (K_NR + U_s * A_NR,1F)
```

代表セルは `床下計算⑦!E6:K8765`、結合結果は
`負荷計算!FZ5:FZ8764`。

**現在の採用判断**

- 床下貫流項には 1F 非居室 19.04 m2を使用する。
- 式 (46)後の実居室温度を使用する。
- 中間期も含め、床下・居室・非居室の順で同一時刻内に評価する。

**A-07の解釈**

- 式 (52)は負荷補正に使う基準状態、式 (48)は能力制約後の実状態を表し、
  同じ出力へ二重加算されるものではない。
- 床下熱収支は参照温度`theta_star`、式 (46)/(48)は実居室・非居室温度を
  使うため、両側の床貫流量には小さな差が生じ得る。この一方向近似は付録 E
  を含む既存計算法から継承したものであり、その範囲の誤差は許容する。
- 反復計算、`t-1`による代用、同一時刻の新しい連立解は導入しない。
