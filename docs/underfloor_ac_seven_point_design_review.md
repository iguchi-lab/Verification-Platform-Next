# 床下空調 7 変更点の数式・採用値・設計検証台帳

## 目的

`260713_説明資料.pptx` の 1 枚目に示された 7 変更点について、
Excel 床下13、仕様書、Verification Platform の関係を一項目ずつ検証する。

この文書は、Excel との一致結果を記録した
`docs/underfloor_ac_excel_alignment.md` を置き換えるものではない。
同文書で Excel 表示桁の一致を確認した計算について、次の問いを改めて扱う。

1. 数式の熱収支と単位は成立しているか。
2. 面積、熱貫流率、温度差係数などの値の選び方は妥当か。
3. 同じ熱移動を別の式で二重に加算・控除していないか。
4. Excel に数式、参照、コピー、分岐上の異常がないか。
5. Excel と仕様書が異なる場合、どちらを最終仕様とするか。

## 資料と判断状態

参照順位は次のとおりとする。ただし、物理的・論理的な妥当性の確認では
Excel を無条件の正解とはしない。

1. Excel 床下13: 現在一致している計算式、評価順、数値
2. `260713_説明資料.pptx`: 7 変更点の設計意図
3. 第三章第一節 Ver.20 付録 E: 床下・地盤の定義
4. 第四章第一節・第二節・第三節: 負荷、ダクト式空調、RAC 能力
5. Verification Platform: 実装可能性、既存 API、非床下経路との整合

各論点の状態は次のいずれかで記録する。

| 状態 | 意味 |
| --- | --- |
| Excel 一致確認済み | 現在のコードが Excel 表示桁に一致している |
| 暫定採用 | Excel 一致のため採用したが、物理的妥当性の対話確認が未完了 |
| 採用確定 | 根拠を確認し、最終仕様として合意した |

## 負荷の出自と二つの区画集合

この計算には、次の二つの異なる区画集合がある。両者を混同しない。

1. **ダクト式全館空調の空調対象**: 暖冷房区画 `i=1～5`
2. **階別負荷按分の参照負荷**: 全室を設定温度とした別の温熱シミュレーションの
   暖冷房区画 `i=1～12`

参照負荷は、別の温熱シミュレーションでは全館空調を直接計算できないため、
全ての部屋を設定温度に保った場合の複数の計算値を組み合わせて作られている。
したがって、式 (40) の階別按分では空調対象 `i=1～5` だけを集計せず、
非居室を含む12区画を次のように階別集計する。

| `i` | 室 | 階 | ダクト式空調の空調対象 | 階別負荷按分に使用 |
| ---: | --- | --- | --- | --- |
| 1 | 居間食堂・台所 | 1F | 対象 | 1F負荷 |
| 2 | 和室 | 1F | 対象 | 1F負荷 |
| 3 | 主寝室 | 2F | 対象 | 2F負荷 |
| 4 | 子供室1 | 2F | 対象 | 2F負荷 |
| 5 | 子供室2 | 2F | 対象 | 2F負荷 |
| 6 | 浴室 | 1F | 対象外 | 1F負荷 |
| 7 | 1F便所 | 1F | 対象外 | 1F負荷 |
| 8 | 洗面所 | 1F | 対象外 | 1F負荷 |
| 9 | ホール | 1F | 対象外 | 1F負荷 |
| 10 | クローゼット | 2F | 対象外 | 2F負荷 |
| 11 | 2Fホール | 2F | 対象外 | 2F負荷 |
| 12 | 2F便所 | 2F | 対象外 | 2F負荷 |

```text
I_1F = {1, 2, 6, 7, 8, 9}
I_2F = {3, 4, 5, 10, 11, 12}

L_mode,1F(d,t) = sum_i in I_1F L_mode(d,t,i)
L_mode,2F(d,t) = sum_i in I_2F L_mode(d,t,i)

r_L,1F(d,t) =
  L_mode,1F(d,t) / (L_mode,1F(d,t) + L_mode,2F(d,t))
```

暖房では `L_mode=L_H`、冷房では `L_mode=L_CS` とする。分母が0の時刻は、
按分対象となる負荷がないため `r_L,1F=0` とする。

## 7 変更点

### ① 式 (40): 風量計算用の熱源機出力

**設計意図**

従来の熱源出力から、すでに見込んでいた床損失を控除し、床下から外気・
地盤への実際の損失を加えて、風量計算用の熱源出力を補正する。

**Excel の主要式**

Excelは1F分の熱源出力を次の床面積比で算出している。

```text
Q_hat_1F = Q_hat * A_HCZ,1F / (A_HCZ,1F + A_HCZ,2F)
          = Q_hat * 46.37 / (46.37 + 34.78)
```

説明資料と今回確認した負荷の出自に従う採用式は、時刻別負荷按分である。

```text
Q_hat_1F(d,t) = Q_hat(d,t) * r_L,1F(d,t)
```

床下温度の一次推定は、暖房を例にすると次の形である。

```text
theta_uf,1 =
  theta_HBR_star
  + (Q_hat_1F * 1000 - Q_floor,old)
    / (rho * c_p * V_1F / 1000 + 3.6 * U_s,vert * A_HCZ,1F)
```

補正後出力は次の熱収支である。

```text
暖房:
Q_hat_corrected =
  Q_hat_base - Q_floor,old + Q_uf_to_ex + Q_uf_to_ground

冷房:
Q_hat_corrected =
  max(Q_hat_base + Q_floor,old - Q_uf_to_ex - Q_uf_to_ground, 0)
```

代表セルは `床下計算①!E6:T8765`、結合結果は `負荷計算!CG5:CG8764`。

**現在の採用判断**

- 1F出力は12区画の時刻別負荷比で按分する。
- 空調対象 `i=1～5` と、負荷按分に使う全室 `i=1～12` を区別する。
- 現行Excelの固定面積按分は修正候補とする。
- 地盤応答、暖冷房の符号と評価順は暫定採用。
- 冷房側の負出力は `max(..., 0)` で制限する。

**物理・Excel 異常候補**

説明資料 4 枚目には「`L_H,1F` は面積按分でなく負荷按分に変更」とあるが、
Excel `床下計算①!E6` は明確に床面積比で按分している。説明資料と Excel の
不一致であり、最優先の対話論点とする。

面積按分比は年間を通じて `0.5714109673` で固定される。一方、コードで再現した
12区画負荷から算出した1F負荷比は次のように時刻変動する。

| モード | 有効時刻 | 負荷比平均 | 最小 | 最大 | 固定面積比との差の平均絶対値 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 暖房 | 3440 | 0.5342969706 | 0 | 1 | 0.1018586862 |
| 冷房顕熱 | 2351 | 0.7014691173 | 0.1335336623 | 1 | 0.1748996998 |

1月1日1時の暖房負荷は、コードでも次の値を再現した。単位は MJ/h である。

```text
i= 1: 5.957166108933446   i= 2: 2.492570330105260
i= 3: 1.538117909322246   i= 4: 1.473408174602586
i= 5: 1.899000840132812   i= 6: 0.517248063997605
i= 7: 0.179072096717445   i= 8: 0.358029707567371
i= 9: 1.476782336365418   i=10: 1.075627711474335
i=11: 1.156551515806655   i=12: 0.410858239396959
```

```text
L_H,1F = L_H,1 + L_H,2 + L_H,6 + L_H,7 + L_H,8 + L_H,9
        = 10.980868643686545 MJ/h

L_H,2F = L_H,3 + L_H,4 + L_H,5 + L_H,10 + L_H,11 + L_H,12
        = 7.553564390735592 MJ/h

r_L,1F = 10.980868643686545 / 18.534433034422136
        = 0.592457758124723
```

以前記録した `0.6324528349` は空調対象 `i=1,2` を `i=1～5` で割った値であり、
今回確認した階別負荷按分の定義には使用しない。固定面積比との差は文言上だけ
ではなく、風量、床下温度、地盤応答、年間結果へ伝播する実質的な数値差である。

コードを12区画負荷按分へ変更し、旧Excel Golden入力で年間計算した結果は
次のとおりである。これはExcelをまだ修正していない段階の影響確認値であり、
新しいGolden基準値としては未採用である。

| 年間結果 | 旧Excel面積按分 | 12区画負荷按分コード | 差 | 変化率 |
| --- | ---: | ---: | ---: | ---: |
| 暖房 | 43,168.736537 MJ/年 | 43,035.945453 MJ/年 | -132.791085 MJ/年 | -0.30761% |
| 冷房 | 18,972.628960 MJ/年 | 18,689.755464 MJ/年 | -282.873496 MJ/年 | -1.49096% |

### ② 式 (52): 負荷バランス時の非居室温度

**設計意図**

非居室の熱収支へ、床下から 1F 非居室床を通る貫流熱を追加する。

**Excel の主要式**

```text
K_1 =
  K_envelope(A_NR=38.93)
  + K_local_vent
  + sum_i(rho * c_p * V_i / 3600 + U_prt * A_prt_i)

K_2 = U_s,vert * A_NR,1F
    = 2.223 * 19.04
    = 42.32592 W/K

暖房:
theta_NR_star =
  (K_1 * theta_HBR_star + K_2 * theta_uf - sum(L_H) * 10^6 / 3600)
  / (K_1 + K_2)

冷房:
theta_NR_star =
  (K_1 * theta_HBR_star + K_2 * theta_uf + sum(L_CS) * 10^6 / 3600)
  / (K_1 + K_2)
```

代表セルは `床下計算②!E6:T8765`、結合結果は `負荷計算!CP5:CP8764`。

**現在の採用判断**

- 外皮・換気項は非居室全体 38.93 m2。
- 床下貫流項だけ 1F 非居室 19.04 m2。
- 両面積を一つの比率へまとめず、別の物理境界として暫定採用。

**物理・Excel 異常候補**

- 19.04 m2 はホール 13.25 m2の全量ではなく 10.76 m2を含む。1F ホール部分を
  10.76 m2とした根拠を図面または面積表で確認する必要がある。
- `U_s,vert=2.223` が床仕上げ・床組を含む実効熱貫流率として妥当かを確認する。

状態: **要確認**

### ③ 式 (8)/(9): 熱損失を含む負荷バランス時の暖冷房負荷

**設計意図**

従来負荷ですでに見込まれた「床を通して外部へ逃げる負荷」を控除し、
床下経路で別途評価する熱収支との二重計上を避ける。

元の12区画負荷を作成した別の温熱シミュレーションでは、床下は室から熱が
逃げる外部側の経路として扱われている。今回の方式では1階床下を給気経路に使い、
床下から室へ熱を供給する。このため、元負荷に含まれる床下への熱損失を
温度差係数 `H_floor=0.7` としていったん控除し、実際の床下温度による熱供給を
式 (46)/(48)側で改めて評価する。これは床経路の二重計上を避けるための
「元負荷の基準条件から今回方式の熱収支への置換」である。

**Excel の主要式**

```text
delta_L_floor_i =
  U_s,load * A_uf_i * (theta_HBR_star - theta_ex)
  * H_floor * 3.6 / 1000

L_star_H_i =
  max(L_H_i + Q_trs_prt_i - delta_L_floor_i, 0)

L_star_CS_i =
  max(L_CS_i - Q_trs_prt_i - delta_L_floor_i, 0)
```

ここでは `U_s,load=0.542226...`、`H_floor=0.7` を使用し、
床下から室への直接貫流に使う `2.223` とは区別する。

代表セルは `床下計算③!E6:H8765`、結合結果は
`負荷計算!DE:DF` と `DL:DM`。

**現在の採用判断**

- 元負荷に含まれる床下への熱損失を `H_floor=0.7` で控除する考え方を採用する。
- 控除対象は元の温熱シミュレーションで既計上の床損失であり、今回の床下から
  室への実熱供給とは別項として扱う。
- Excel の符号、`max(..., 0)`、評価順を暫定採用。
- 説明資料 9 枚目にも「仕様書の式が違っている模様」とあり、仕様書との差を
  未解決のまま Excel へ合わせている。

**物理・Excel 異常候補**

- 暖房・冷房の符号が、`theta_HBR_star - theta_ex` の正負も含めて意図した
  控除方向になるか、代表的な冬・夏・中間期で確認する。
- 式 (40)、式 (46)/(48) と合わせた全熱収支で、同じ床貫流を二重控除または
  二重加算していないかを確認する。

状態: **要確認**

### ④ 式 (21): 熱源出口の要求空気温度（Pass 1）

**設計意図**

補正後負荷から目標床下温度を求め、その温度を成立させる熱源出口温度を
床下熱収支の直接逆算で求める。

**Excel の主要式**

```text
暖房目標:
theta_uf,target =
  theta_HBR_star
  + sum(L_star_H_1F) * 1000
    / (C_sa + 3.6 * U_s,vert * A_HCZ,1F)

冷房目標:
theta_uf,target =
  theta_HBR_star
  - sum(L_star_CS_1F) * 1000
    / (C_sa + 3.6 * U_s,vert * A_HCZ,1F)
```

床下全体の損失係数を次のように置く。

```text
K_1 = U_s,vert * A_s,ufvnt,A * H_star
K_2 = psi * L_uf
K_3 = A_s,ufvnt,A / (R_g + phi_A,0)
K = K_1 + K_2 + K_3

P = K_1 * theta_HBR_star
  + K_2 * theta_ex
  + K_3 * (sum(theta'_g,surf,A) + theta_g,avg)
```

要求熱源出口温度は次の直接逆算である。

```text
theta_req =
  (theta_uf,target * (C_sa + 3.6 * K) - 3.6 * P) / C_sa

暖房: theta_req = max(theta_req, 20)
冷房: theta_req = min(theta_req, 27)
```

代表セルは `床下計算④!G6:S8765`。

**現在の採用判断**

- 二分探索は使わず、Excel の直接逆算を採用。
- `t-1` の床下温度は代用しない。
- 前時刻状態は付録 E の地盤応答モデル内部だけで保持する。
- 20 C / 27 C の制限と熱源能力制約の適用順を暫定採用。

**物理・Excel 異常候補**

- 目標床下温度の式では 1F 居室 46.37 m2を使う一方、要求温度の逆算では
  床下接触面積 65.41 m2を使う。この境界の違いが意図したものか確認する。
- `C_sa=0` または非常に小さい無負荷時刻の扱いは、Excel 数式だけでは
  安全性が明示されない。コードは負荷・風量分岐で除外している。

状態: **要確認**

### ⑤ 式 (41): 暖冷房区画の吹出温度（Pass 2）

**設計意図**

能力制約後の実熱源出口温度から、床下熱収支を順方向に解き、居室へ届く
実際の供給温度を求める。

**Excel の主要式**

```text
theta_supply =
  [C_sa * theta_hs_out
   + 3.6 * {
       K_1 * theta_HBR_star
       + K_2 * theta_ex
       + K_3 * (sum(theta'_g,surf,A) + theta_g,avg)
     }]
  / [C_sa + 3.6 * (K_1 + K_2 + K_3)]
```

代表セルは `床下計算⑤!P6:P8765`、結合結果は
`負荷計算!FM5:FN8764`。

**現在の採用判断**

- Pass 1 と同じ係数・地盤応答項を使う。
- 能力制約前の要求温度ではなく、制約後の `theta_hs_out` を使う。
- 居室 1、2には共通床下空間の同じ供給温度を出力する。

**物理・Excel 異常候補**

- 居室 1、2に同じ温度を与えることは完全混合床下を仮定している。この仮定が
  対象方式の設計意図に合うか確認する。
- 床下内の局所温度分布、経路長、漏気はモデル化されない。

状態: **暫定採用**

### ⑥ 式 (46): 暖冷房区画の実際の居室温度

**設計意図**

従来の給気による熱供給に加え、床下から床を通る直接熱供給を居室熱収支へ
追加し、実際の居室温度を求める。

**Excel の主要式**

暖房側を概念式で表す。

```text
theta_HBR_i =
  max[
    theta_HBR_star,
    theta_HBR_star
    + {
        rho * c_p * V_i * (theta_supply - theta_HBR_star)
        + 3600 * U_s,vert * A_uf_i
          * (theta_uf - theta_HBR_star)
        - L_star_H_i * 10^6
      }
      / {
        rho * c_p * V_i
        + 3600 * U_s,vert * A_uf_i
        + 3600 * (U_prt * A_prt_i + Q * A_i)
      }
  ]
```

冷房側は負荷符号を反転し、`min(theta_HBR_star, ...)` を使う。
代表セルは `床下計算⑥!E6:H8765`、結合結果は
`負荷計算!FT5:FU8764`。

**現在の採用判断**

- Pass 2 後の実供給温度を使用する。
- 暖房は基準室温以上、冷房は基準室温以下へ制限する。
- 給気と床貫流を別の熱供給経路として暫定採用。

**物理・Excel 異常候補**

- 式 (8)/(9)で元の床負荷を控除し、式 (46)で床下からの貫流を追加する構成が
  全体系で一回ずつの計上になっているかを確認する。
- `theta_supply` と `theta_uf` が同じ系列であるため、空気経路と貫流経路の
  二つの項が物理的に独立していることを明示する必要がある。

### ⑦ 式 (48): 実際の非居室温度

**設計意図**

非居室の実熱収支へ、1F 非居室床を通る床下からの供給と、実居室温度による
間仕切熱移動の変化を反映する。

```text
theta_NR =
  {
```
